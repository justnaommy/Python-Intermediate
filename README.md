
# Python Intermediate Project

This folder contains a collection of Python practice exercises, data analysis scripts, and a small web scraping mini-project.

## Project Overview

The files in this folder are mainly focused on:

- Data cleaning and preprocessing
- Machine learning and classification examples
- CSV dataset exploration
- Web scraping with Selenium

## Main Files

### Data and ML Practice
- `1stcontact.py` – introductory Python script or practice file.
- `3rd Contact.py` – Titanic dataset preprocessing and Random Forest classification example.
- `3rd Contact1.py` – additional contact/practice file related to the same learning workflow.
- `3rdContact2.py` – continuation of intermediate Python/data learning practice.
- `4thContact.py` – another exercise file in the same project series.
- `6thcontact.py` – more Python practice or exploratory code.

### Datasets
The folder includes several CSV files used for exercises and modeling:

- `Titanic.csv`
- `Titanic 2.csv`
- `titanic_submission.csv`
- `train.csv`
- `test.csv`
- `cleaned_data.csv`
- `spam_ham_dataset.csv`
- `fifa21_raw_data.csv`

These datasets are likely used for experimentation, feature engineering, and classification tasks.

### Web Scraping Project
The `book_scraperproject/` folder contains a Selenium-based web scraping example:

- `book_scraper.py` – scrapes book information from Books to Scrape and saves it to `books.csv`.
- `quote_scrape.py` – scrapes quote and author details from Quotes to Scrape.
- `books.csv` – output data generated by the scraper.
- `chromedriver.exe` – browser driver used by Selenium for Chrome automation.

## Notes

- This project appears to be a learning workspace for Python intermediate topics.
- Some scripts may be incomplete, experimental, or duplicated as part of practice.
- The scraping scripts depend on Selenium and a compatible ChromeDriver setup.

## Suggested Next Step

Open the files in order and run them individually to understand the progression from basic Python practice to data exploration and web scraping.
